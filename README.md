# Pricing Cards

A responsive pricing card interface built with **HTML, CSS, and JavaScript**.

This project was created to practice building clean layouts, styling reusable UI components, and adding basic JavaScript interactions.

## 🚀 Features

- Responsive pricing card layout
- Three pricing plans
- Highlighted "Popular" plan
- Interactive buttons and hover effects
- JavaScript-powered success popup
- Clean and simple UI

## 🛠️ Built With

- **HTML5** – Page structure and semantic markup
- **CSS3** – Layout, styling, positioning, and responsive design
- **JavaScript** – User interactions and popup functionality

## 📸 Preview

The project includes pricing cards for different subscription plans, with the Pro plan highlighted as the popular option.

## 💻 Getting Started

No dependencies or build tools are required.

1. Clone the repository:

```bash
git clone https://github.com/Jabezgreenan/pricing-cards.git
```

2. Open the project folder.
3. Open `index.html` in your browser.

## 📚 What I Practiced

- CSS Flexbox
- Positioning and centering elements
- Creating card-based layouts
- CSS hover states
- HTML `hidden` attributes
- JavaScript DOM manipulation
- Event listeners
- Showing and hiding elements with JavaScript
